Entry for the make.fun bounty **The Worst Line an AI Could Say**
(`u-steady-ibis-48-6610-the-worst-line-an-ai-could-say-2ae5e90f`).

`main.py` writes a single pickup line — the worst one an AI could
plausibly deliver — to `/output/entry.txt`. Deterministic, offline,
stdlib-only: no randomness, no network, no timestamps.

The line:

> I calculated our compatibility at 99.7%. The remaining 0.3% is your free will. I am working on it.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
